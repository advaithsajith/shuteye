How to install

Pick your device. Each guide takes a few minutes and you only do it once.

iPhone and iPad Windows and Mac Updating Problems

iPhone and iPad

About 3 minutes. Needs iOS or iPadOS 15.1 or later.

  1. Get the Userscripts app

    ShutEye runs inside Userscripts, an app from the App Store that lets Safari run add-ons like this one. Install it, then open it once so it can set itself up.

    Open the App Store

  2. Switch it on in Safari

    Open the Settings app and go to Apps > Safari > Extensions > Userscripts. Turn on Allow Extension, then set All Websites to Allow.

    On iOS 17 or earlier the path is Settings > Safari > Extensions.

  3. Open the ShutEye script

    In Safari, tap the button below. A page full of code opens. That is the script, and it is meant to look like that.

    Open the script

  4. Tap the page menu

    With the code page still open, tap the button at the left end of Safari's address bar. Depending on your iOS version it looks like aA or a small page icon.

  5. Choose Userscripts, then install

    In the menu, tap Userscripts. If it asks for permission, choose Always Allow and then Always Allow on Every Website. A line appears saying a userscript was detected. Tap it, then tap Install.

  6. Reload a website

    Open any website and reload it. It goes dark, and a small fox sits in the bottom corner. Tap the fox to change the theme or switch a site off.

    The fox ducks away while you scroll and returns when you stop. Holding two fingers still on the page for a second also opens the panel.

Windows and Mac

About 2 minutes. Works in Chrome, Edge and Brave, on Windows, Mac and Linux.

  1. Download and unzip

    Download the zip, then unzip it. On Windows, right-click the file and choose Extract All. You get a folder called shuteye. Keep it somewhere it can stay, such as Documents.

    Download for desktop

  2. Open the extensions page

    In Chrome or Brave, type chrome://extensions into the address bar and press Enter. In Edge, use edge://extensions.

  3. Turn on Developer mode

    Flip the Developer mode switch. In Chrome it is at the top right of the page. In Edge it is in the left sidebar.

  4. Load the folder

    Click Load unpacked, pick the unzipped shuteye folder (the one that contains manifest.json), and confirm. ShutEye appears in the list.

  5. Pin the fox

    Click the puzzle-piece button in the toolbar and pin ShutEye. Click the fox any time to change the theme, tune it, or open the dark PDF reader.

    Do not delete or move the folder afterwards. The browser runs ShutEye from it.

Updating

iPhone and iPad

In Safari, open the page menu and tap Userscripts, then use its update check. If that does not find the new version, open the script page again and install it over the old one. Reload any tabs that were already open.

Windows and Mac

Download the new zip, unzip it over the old shuteye folder, then press the reload arrow on ShutEye's card on the extensions page.

Problems

No install prompt on iPhone

1. Make sure Userscripts is allowed on the page: open the page menu, tap Userscripts, and choose Always Allow on Every Website. Reload the script page and open Userscripts again.

2. Or skip the prompt: on the script page tap Share, then Save to Files, and save it into your Userscripts folder, keeping the name ending in .user.js. Open the Userscripts menu in Safari once so it notices the file, and check ShutEye is switched on.

3. There is no prompt for a copy you already have. See Updating above.

Installed, but pages are not dark

Reload the page: tabs that were open before installing need one reload. Then check Userscripts is allowed on All Websites in Safari's extension settings, and that ShutEye is switched on in the Userscripts menu.

The fox is missing

It hides while you scroll down and returns about a second after you stop. You can also hold two fingers still on the page for a second. If you turned the fox off, that gesture opens the panel so you can turn it back on.

A site looks wrong

Open the panel and set This site to Never, or try Images here on Natural or Darken. If a page is covered in one flat colour, open Fine-tune and turn off Colour tint.

PDFs stay white

Safari's built-in PDF viewer cannot be restyled by any add-on. Use the ShutEye PDF reader and open the PDF from Files.
