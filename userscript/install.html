Lights out for every website

Dark mode for Safari on iPhone and iPad, in a theme you choose. Photos keep their real colours. Free to use, and nothing leaves your device.

On iPhone and iPad

Not installed on this browser yet.

First time? The step-by-step guide shows exactly where to tap.

  1. Get Userscripts

    ShutEye runs inside Userscripts, an open-source Safari extension from the App Store. Install it and open it once.

    Open the App Store

  2. Switch it on

    Turn Userscripts on for Safari and allow it on all websites.

    Settings > Apps > Safari > Extensions > Userscripts > Allow Extension, then All Websites > Allow.
    On iOS 17 or earlier: Settings > Safari > Extensions.

  3. Add ShutEye

    Tap the button. When the script opens, tap the page-menu button in Safari's address bar, choose Userscripts, and tap the install prompt.

    Install ShutEye
    No install prompt?

    1. With the script page open, tap the page-menu button, then Userscripts. If it asks, choose Always Allow, then Always Allow on Every Website. Reload the script page and open Userscripts again.

    2. Still nothing? On the script page tap Share, then Save to Files, and save it into your Userscripts folder (keep the name ending in .user.js). Open the Userscripts menu in Safari once so it notices the file, and check ShutEye is switched on.

    3. Already have ShutEye? There is no prompt for a copy you already have. Open the Userscripts menu and use its update check instead.

  4. Meet the fox

    Reload any website. It goes dark, and a small fox sits in the corner. Tap the fox to pick a theme, tune it, or switch a site off.

    No fox? Hold two fingers still on the page for a second.

On a computer

ShutEye also runs in Chrome, Edge and Brave on Windows, Mac and Linux, with a proper toolbar button.

Download and unzip it. Open chrome://extensions (or edge://extensions), switch on Developer mode, choose Load unpacked, and pick the unzipped folder.

Read PDFs

Safari's own PDF viewer cannot be restyled, so ShutEye has a reader of its own. Open a PDF from Files and it is drawn in your theme, on this device only.
